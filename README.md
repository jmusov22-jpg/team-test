# Мультитул Tkinter

Простий графічний застосунок на Python для базової роботи з текстом. App створено з використанням бібліотеки `tkinter` і призначений для швидких операцій над введеним рядком.
![alt text](<Знімок екрана 2026-10-17 140440.png>)
## Опис проекту

Цей проєкт є невеликим текстовим інструментом з інтерфейсом, який дозволяє:

- вітатися з користувачем;
- рахувати кількість символів у введеному тексті;
- перевертати текст задом наперед;
- переводити текст у верхній регістр;
- очищати поле введення та результат.

## Технології

- Python 3
- Tkinter (стандартна бібліотека GUI для Python)

## Вимоги

Перед запуском переконайтеся, що на вашій системі встановлено Python 3.x.

Для Windows, macOS та Linux Tkinter зазвичай входить до стандартної поставки Python, тому додатково встановлювати його зазвичай не потрібно.

## Запуск проєкту

Виконайте команду:

```bash
python "team test.py"
```

Якщо у вас на комп'ютері файл запускається як Python-скрипт, також можна відкрити файл `team test.py` у середовищі розробки та запустити його через інтерпретатор.

## Функціональність

### 1. Привітатися
Після введення тексту натисканням кнопки `Привітатися` програма виводить повідомлення типу:

```text
Привіт, <ваш текст>!
```

### 2. Порахувати символи
Показує загальну кількість символів у введеному рядку.

### 3. Перевернути текст
Виводить текст у зворотному порядку.

### 4. У великі літери
Перетворює введений текст на верхній регістр.

### 5. Очистити
Очищує поле введення і скидає результат.

## Приклад використання

1. Введіть текст у поле `Введіть текст:`.
2. Натисніть одну з доступних кнопок.
3. Результат відобразиться під кнопками.
