# TeamChat

Односторінковий чат-інтерфейс, у якому можна керувати профілем і контактами, створювати групи та зберігати історію розмов у браузері.

## Запуск

Для запуску достатньо відкрити [index.html](./index.html) у браузері. Якщо потрібен сервер, виконайте:

```bash
cd "C:\Users\UserHome\Documents\GitHub\team-test"
python -m http.server 8000
```

Після цього відкрийте <http://localhost:8000>.

Додаткові залежності не потрібні.

## Можливості

- вибір чату зі списку;
- редагування імені, контактних даних, аватара та кольору профілю;
- створення секретного коду профілю та додавання контактів за номером телефону, імейлом або кодом;
- створення груп із контактів;
- введення та надсилання повідомлення кнопкою або клавішею Enter;
- вибір стікера з меню біля поля повідомлення;
- відображення нового повідомлення у вибраному чаті;
- оновлення прев'ю останнього повідомлення у списку;
- локальне збереження профілю, контактів, груп, вибраного чату та історії повідомлень між відкриттями сторінки;
- адаптивний інтерфейс для телефонів і вузьких екранів.

Дані зберігаються у `localStorage` цього браузера й не синхронізуються з іншими пристроями або користувачами. Щоб додати контакт, введіть його ім’я та щонайменше один ідентифікатор, яким він із вами поділився. Секретний код генерується у профілі; передавайте його лише людям, яких хочете додати.

## Структура

- [index.html](./index.html) — розмітка сторінки;
- [style.css](./style.css) — стилі та мобільна адаптація;
- [script.js](./script.js) — дані чатів і логіка вибору та надсилання.
