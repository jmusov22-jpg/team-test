# TeamChat

Односторінковий чат-інтерфейс, у якому можна вибрати співрозмовника, написати повідомлення та одразу побачити його у відкритій розмові.

## Запуск

Відкрийте [index.html](./index.html) у браузері. Додаткові залежності не потрібні.

## Можливості

- вибір чату зі списку;
- введення та надсилання повідомлення кнопкою або клавішею Enter;
- відображення нового повідомлення у вибраному чаті;
- оновлення прев'ю останнього повідомлення у списку;
- адаптивний інтерфейс для телефонів і вузьких екранів.

## Структура

- [index.html](./index.html) — розмітка сторінки;
- [style.css](./style.css) — стилі та мобільна адаптація;
- [script.js](./script.js) — дані чатів і логіка вибору та надсилання.
